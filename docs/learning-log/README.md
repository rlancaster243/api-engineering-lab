# Learning log

Use this folder for dated notes as you work through the lab. One file per session or per milestone keeps reflection lightweight and searchable.

## Template

Copy the block below into a new file named `YYYY-MM-DD-short-topic.md`.

```markdown
# YYYY-MM-DD — Short topic

## What I did

- 

## What I learned

- 

## Questions / next

- 

## Links

- PR, docs, or external references
```

## Conventions

- Prefer **present tense** for facts that still hold ("The health endpoint returns 200").
- Link to the project directory (`01-rest-api`, etc.) when the note is module-specific.
- Record failed experiments — they are as valuable as successes for an engineering log.
